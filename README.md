# AI Home Builder Analyzer

Description: Takes user input such as zip code, square footage, number of beds, etc and returns an AI powered response on construction costs and plans for residential home builds using Gemini API. 

## Installation

1. Download or clone this repository into your desired directory.
2. Run `npm install` to install dependencies.

## Key Scripts
| Command        | Description                                                                                      |
| :------------- | :----------------------------------------------------------------------------------------------- |
| `npm run dev`  | Starts local development server at `localhost:5173`                                              |
